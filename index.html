Bantuan

Cara top up

Pilih game, pilih nominal, isi Username/ID game, lalu bayar lewat QRIS atau saldo. Untuk QRIS, kirim bukti bayar ke WhatsApp admin lewat tombol yang tersedia. Admin akan memproses pesananmu setelah pembayaran dicek.

Kenapa ada kode unik di total bayar?

Kode unik 3 angka membantu admin mengenali pembayaranmu. Bayar persis sesuai total yang tertera, termasuk kode uniknya.

Cara deposit saldo

Daftar atau masuk sebagai member, buka akunmu, pilih Deposit via QRIS, lalu bayar sesuai total. Saldo bertambah setelah admin mengonfirmasi pembayaranmu.

Bagaimana melihat status pesanan?

Buka menu Cek Pesanan dan masukkan ID transaksimu. Member juga bisa melihat semua transaksinya di tab Riwayat pada menu akun.

Salah memasukkan ID game?

Segera hubungi admin lewat WhatsApp dengan menyebutkan ID transaksimu. Pesanan yang sudah diproses tidak selalu bisa dibatalkan.

Syarat & Ketentuan singkat

Pastikan Username/ID game dan nominal sudah benar sebelum membayar. Kesalahan input dari pembeli menjadi tanggung jawab pembeli. Pesanan diproses setelah pembayaran terkonfirmasi.

Kebijakan Privasi singkat

Kami menyimpan email, riwayat transaksi, dan ID game hanya untuk memproses pesanan dan menampilkan riwayatmu. Data tidak dijual kepada pihak lain.
